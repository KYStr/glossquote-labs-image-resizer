How to prepare an image for size limits

  1. Choose or drop one static PNG or JPEG.
  2. Set the longest edge, width or height. Proportions always stay locked.
  3. Choose PNG, JPEG or browser-supported WebP. JPEG composites transparency onto white.
  4. If a form has a file size limit, enable “Set a file size limit”, enter a whole number and choose kB, KiB or bytes. 200 kB = 200,000 bytes; 200 KiB = 204,800 bytes.
  5. Generate and inspect actual format, dimensions, bytes, quality and attempts. A download appears only within the limit. Otherwise, choose smaller dimensions or another format and try again.

Supported formats and limits

Input is one nonempty static PNG or 8-bit baseline/progressive JPEG up to 10 MiB (10,485,760 bytes), with each side from 1 to 8,192 pixels and no more than 12,000,000 pixels in total. Container dimensions are checked before decoding. Animated PNG, GIF, HEIC, SVG, WebP input, image URLs and batches are unsupported.

The tool reduces size without cropping. Enter an integer from 1 to 4,000 pixels; output cannot exceed 8,000,000 pixels or enlarge the original. The other edge is rounded and stays at least 1 pixel. The default longest edge is the smaller of the original longest edge and 1,920 pixels.

PNG and WebP preserve transparency. JPEG quality defaults to 85 and accepts 1–100. WebP is enabled only when the browser returns its actual MIME type. Startup checks all eight EXIF orientations and basic formats; processing is disabled if the checks fail. Desktop Chromium 155.0.8059.40 has been tested. Firefox, Edge, Safari and physical mobile devices remain unverified.

File size mode checks exact bytes. JPEG/WebP make up to 12 sequential quality attempts within a 30-second deadline. The first qualifying result can be downloaded; this is not a search for the highest possible or optimal quality. PNG is generated and checked once. A failed attempt never changes dimensions or format automatically and has no download.

Files stay in this page

Images are processed in your browser without an image upload flow or writes to browser storage. The website’s HTML, JavaScript and CSS still need to load. Hosting providers may receive ordinary resource-request connection information.

Clear releases the image, result and object URLs held by this page. It does not delete files you have already downloaded. Browser caches and memory collection remain under the browser’s control. Cancel discards a late encoding result but cannot guarantee that native encoding stops immediately.

Frequently asked questions

Why might the file size limit be unreachable?

PNG cannot be adjusted to an arbitrary size through quality. JPEG/WebP may also exceed the limit after all bounded attempts. No download is offered without a qualifying result. Choose smaller dimensions or another format and try again.

What happens to transparency in JPEG?

JPEG does not preserve transparency. This tool always composites transparent areas onto white. PNG and supported WebP preserve transparency; the checkerboard is only a preview background.

Are my images uploaded?

The tool processes selected files in this browser page and has no image upload flow. This does not guarantee that your device or browser has no other network activity.

Are phone photos and animations supported?

This version accepts only static PNG and JPEG files within the limits. HEIC, GIF and animated PNG are unsupported. Physical mobile browser compatibility is not yet verified.

Are EXIF, color profiles and print DPI preserved?

EXIF orientation is applied during decoding. The tool does not copy original EXIF, GPS or ICC segments, does not promise completely metadata-free output, and does not preserve print color or DPI. Color conversion uses browser defaults and may differ between browsers.
