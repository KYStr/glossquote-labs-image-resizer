如何準備指定尺寸與容量的圖片

  1. 選擇或拖入一張靜態 PNG 或 JPEG。
  2. 依最長邊、寬或高設定尺寸；長寬比例始終鎖定。
  3. 選擇 PNG、JPEG，或瀏覽器可用的 WebP。JPEG 會把透明區合成白底。
  4. 需要符合表單容量時，開啟「設定容量上限」，填入整數並明確選 kB、KiB 或 bytes。200 kB＝200,000 bytes；200 KiB＝204,800 bytes。
  5. 產生並查看實際格式、尺寸、bytes、品質與嘗試次數。達標才提供下載；未達時可自行降低尺寸或換格式後再試。

支援格式與限制

輸入限單張、非空、最多 10 MiB（10,485,760 bytes）的靜態 PNG 或 8-bit baseline／progressive JPEG；每邊 1–8,192 px、總像素最多 12,000,000。先檢查容器尺寸，再解碼；動畫 PNG、GIF、HEIC、SVG、WebP 輸入、網址與批次不支援。

只縮小、不裁切。目標尺寸為整數 1–4,000 px，輸出最多 8,000,000 像素，不放大。次要邊會四捨五入且至少 1 px。預設最長邊為原圖最長邊與 1,920 的較小值。

PNG 與 WebP 保留透明度；JPEG 品質預設 85，範圍 1–100。WebP 依實際編碼能力開放。瀏覽器啟動時會自測 EXIF 八方向與基本格式；未通過時停用處理。實測版本為桌面 Chromium 155.0.8059.40；Firefox、Edge、Safari 與實體手機仍未驗證。

容量模式以 exact bytes 核對上限。JPEG／WebP 最多依序嘗試 12 次、總期限 30 秒；第一個符合上限的結果可下載，不保證最高可能或最佳品質。PNG 不搜尋品質，只產生一次核對。未達標不自動改尺寸或格式，不提供未達標下載。

檔案留在這個頁面

圖片在瀏覽器內處理，沒有圖片上傳流程，不寫入瀏覽器儲存。網站的 HTML、JS 與 CSS 本身仍需載入；託管方可能收到一般資源請求的連線資訊。

清除會釋放本頁持有的圖片、結果與物件網址，不會刪除已下載的檔案。瀏覽器的底層快取與記憶體回收仍由瀏覽器管理。取消編碼會丟棄晚到結果，但無法保證原生編碼立即停止。

常見問題

為什麼容量上限可能達不到？

PNG 無法用品質調整到任意容量。JPEG／WebP 也可能在有限次品質嘗試後仍超出上限；沒有達標結果就不提供下載。可自行降低尺寸或選其他格式後再試。

透明背景轉 JPEG 會怎樣？

JPEG 不保留透明度，本工具固定以白色作為背景。PNG 與可用的 WebP 則保留透明度；棋盤格只用於預覽。

會上傳圖片嗎？

工具在這個瀏覽器頁面處理所選檔案，沒有圖片上傳流程。這不等於保證裝置或瀏覽器沒有其他網路活動。

支援手機照片與動圖嗎？

第一版只接受符合限制的靜態 PNG／JPEG。HEIC、GIF 與動畫 PNG 不支援；實體手機相容性尚未驗證。

EXIF、色彩與印刷 DPI 會保留嗎？

EXIF 方向會在解碼時套用。工具不複製原始 EXIF、GPS 或 ICC 片段，不保證輸出所有 metadata 都完全清空，也不提供印刷色彩或 DPI 保真。色彩轉換採瀏覽器預設，不承諾不同瀏覽器逐像素一致。
